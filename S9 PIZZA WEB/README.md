# S9 PIZZA - Your Favorite Street Kitchen

Welcome to the **S9 PIZZA** website repository! This is a modern, responsive, and beautifully designed landing page for a local pizza counter.

## 🌟 Features

- **Modern UI/UX**: Built with a sleek, cloud-themed aesthetic inspired by modern food apps.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Scroll Animations**: Bouncy, dynamic scroll animations that bring the page to life as users scroll down.
- **Fast Performance**: Built with raw HTML, vanilla Javascript, and Tailwind CSS (via CDN) for lightning-fast loading speeds.
- **Custom Fonts**: Uses Google Fonts ('Outfit', 'Fredoka', and 'Permanent Marker' for handwriting accents).

## 🛠 Tech Stack

- **HTML5**
- **Tailwind CSS** (via CDN for zero-build-step styling)
- **Vanilla Javascript** (for Intersection Observer scroll animations)
- **CSS3** (for custom keyframe animations and floating effects)

## 🚀 Deployment

This project consists of static files (`index.html`, `style.css`, `script.js`) and can be deployed instantly to any static hosting provider.

### Deploying to Vercel

If you ever encounter a `404 NOT_FOUND` error on Vercel, it usually means Vercel can't find your `index.html` file at the root URL.

**Fixing it via GitHub Deployment:**
1. Go to your project on the Vercel Dashboard.
2. Navigate to **Settings** > **General**.
3. Under **Root Directory**, type the exact folder name containing your website (e.g., `S9 PIZZA WEB`).
4. Save and trigger a new deployment.

**Fixing it via Manual Drag-and-Drop:**
Make sure you drag and drop the `S9 PIZZA WEB` folder itself directly into Vercel, and not the parent folder (like your `Movies` folder).

## 📁 File Structure

- `index.html` - The main layout, content, and structure of the page.
- `style.css` - Custom CSS overrides, floating keyframes, and scroll animations.
- `script.js` - Lightweight Intersection Observer script to trigger the bouncy entrance animations.
